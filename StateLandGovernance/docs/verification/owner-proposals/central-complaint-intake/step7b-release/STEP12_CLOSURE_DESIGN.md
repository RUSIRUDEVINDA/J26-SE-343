# Step 12 implementation design

Per-finding officer closure is an additional C4 application follow-up operation, `FindingVerifiedClosed`. Existing evaluation results, rules, identifiers, rule versions and evidence states remain immutable. Status Recorded remains the audit-event storage state; Verified & Closed is the distinct current officer disposition.

Initial policy establishes DS authority only for the saved NPD-LOC-001 and NPD-RAT-001 version 1.0 completeness requirements with the expected NPD source and exact requirement. Unknown versions/requirements, other obligations, blocking findings and any recorded institutional/legal-review referral fail closed with a reason. Generic RequiresHumanReview on these two known DS-reviewable requirements is fulfilled by the responsible DS's reasoned closure; it is not interpreted as independent approval. Every closure requires substantive remarks and specific supporting evidence references. References record officer-reviewed support, not independently verified uploaded documents or external approvals.

The existing transaction, ownership rechecks, submission replay identity, immutable canonical hashes and expected per-rule revision protect the write. Closure is terminal for that saved finding. Same-key replay returns the original event; a new duplicate closure or other later follow-up is rejected. Other rule streams remain unaffected. Progression recognizes only a valid, policy-eligible closure for its matching rule/version; all other holds remain.

Schema change: widen only the existing operation CHECK for the new payload and add a partial unique index on evaluation/rule for closure operations. No column, data update, deletion, privilege or model/rule change. Existing rows satisfy the widened CHECK and contain no new operation, so the new index has no existing duplicate inputs. Generate an additive EF migration with a matching model snapshot; prevent destructive Down. Apply and verify solely against the guarded Docker test database on port 57657. Ordinary activation/migration is outside this task.
