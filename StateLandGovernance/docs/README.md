# Documentation

Documentation for the State Land Governance backend. Folders are placeholders for future content.

| Folder | Purpose |
|---|---|
| **architecture/** | System architecture diagrams, ADRs, module boundaries, dependency rules |
| **api/** | OpenAPI specs, endpoint contracts, request/response examples |
| **database/** | PostgreSQL schemas, EF Core mappings, PostGIS spatial models |
| **knowledge-graph/** | Neo4j graph model, node/relationship definitions, Cypher queries |
| **ai/** | ML model documentation, training data, inference pipelines |
| **deployment/** | Docker Compose, Kubernetes manifests, CI/CD pipelines, environment config |
